# 化学災害 産業保健ポータル

化学工場の爆発・漏えい時に、産業医・保健師・衛生管理者・救護班が最初の 120 分で判断し支援するための学習ポータルと、
ALOHA と同じ枠組みの化学物質拡散シミュレーター。

- 学ぶ：8 モジュール（化学災害の基礎／基準値の使い分け／最初の 120 分／ゾーニング・除染／医療連携／リハブ／平時の備え／拡散予測の読み方）
- ケース演習：折尾ケミカル西工場 アンモニア漏えい爆発（架空）
- 拡散シミュレーター：脅威ゾーン（AEGL・PAC・ERPG）、風向の信頼線、地点ごとの屋外・屋内濃度と AEGL 比較、指揮官への助言文
- 爆風圧の目安：TNT 換算法（8.0・3.5・1.0 psi）
- 物質・基準値：15 物質の AEGL・PAC・ERPG・IDLH・許容濃度・管理濃度。PubChem から現行値を取得して照合、他の物質も検索
- 用語集・計算方法・出典

## 起動

```
python3 -m http.server 8666
```

## 未確認事項・今後の確認

- ERPG は PubChem 経由の Haz-Map の値。AIHA の最新ハンドブックとの照合は未了。
- ACGIH TLV は ILO ICSC 等の二次資料で確認（原本は有料冊子）。
- 液密度・液比熱は文献値の概数（±10%）。
- Britter & McQuaid のパフの係数表は 1 資料（GasDispersion.jl、CCPS 1999 から転記）のみで確認し、連続性で検査。
- Wilson (1987)・Raphael (1962)・Hanna (2020) の書誌は一部未確認。
- ALOHA の風向の信頼線は低風速で円になるとされるが、その条件は技術文書に記載がなく、本アプリは文書の式のみ実装。
